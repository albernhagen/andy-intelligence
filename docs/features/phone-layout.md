# Phone layout

Below 640 px the app uses its phone layout: navigation in a bottom bar (Inbox, Board, Dashboards, More; More lists Roadmap, Work, What's new, then every settings page and Sign out, AI-335), 44 px touch targets, iPhone safe areas respected (AI-173: M7.3: Phone shell). No screen scrolls sideways; only the board's lanes scroll, inside their own strip (AI-325: Phone: no screen scrolls sideways)

**How to use:** Open the app on a phone, or narrow the browser window
