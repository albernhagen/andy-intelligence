# Needs-you inbox

A list of tickets beside the picked one's decisions (AI-371): one row per ticket, most unblocking first; the picked ticket's questions show on the right, each answer with the key that picks it (`1`–`9`, numbered across the ticket) and one-click answers; "Accept all suggested" is the one primary button. Each answer is confirmed in a toast, with no Undo because the API can't withdraw an answer. On a phone, one decision at a time with its place in the queue ("Ticket 3 of 5 · question 1 of 2") and Previous / Next. Every count is tickets, not questions: the header "Needs you N", the picker, the inbox headings and MCP `list_needs_me` `counts` agree (AI-347); refine questions stand alone (context, options with costs, a recommendation); same in Claude via the `/inbox` skill. **Epic breakdowns** (AI-383): drafted tickets waiting for approval, each linking to its epic's panel, where Andy decides ([epic breakdown](epic-breakdown.md)). **Waiting for your merge** (AI-218): clean PRs the merge mode leaves for you (no mode saved, manual, a kept or high-risk path, a finding you accepted), in board order, each with why and its release note; merging or closing one drops it. MCP `list_needs_me` returns the same list as `waitingMerges`. It checks at most 20 tickets in review per read and reads each PR's description at most every 5 minutes

**How to use:** UI home `/`: last-picked project or All projects
