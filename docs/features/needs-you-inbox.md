# Needs-you inbox

A card per ticket, most unblocking first, one-click answers. Every count is tickets, not questions: the header "Needs you N", the picker, the inbox headings and MCP `list_needs_me` `counts` agree (AI-347); refine questions stand alone (context, options with costs, a recommendation); same in Claude via the `/inbox` skill. **Waiting for your merge** (AI-218): clean PRs the merge mode leaves for you (no mode saved, manual, a kept or high-risk path, a finding you accepted), in board order, each with why and its release note; merging or closing one drops it. MCP `list_needs_me` returns the same list as `waitingMerges`. It checks at most 20 tickets in review per read and reads each PR's description at most every 5 minutes

**How to use:** UI home `/`: last-picked project or All projects
