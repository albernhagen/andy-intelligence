# Claude connector (MCP)

Claude desktop via our OAuth server; tools: create, refine, build, answer, promote an assumption, move (one step forward), edit, comment, re-parent, reorder, cancel, archive; approve/reject plans; `status`, `list_ready` (scored; filter by size, risk, confidence), `list_projects`, project switches, `submit_brief` (brief PR), `ideate` (epic, spec PR); UI rules

**How to use:** [`docs/runbooks/mcp-connector.md`](../runbooks/mcp-connector.md)
