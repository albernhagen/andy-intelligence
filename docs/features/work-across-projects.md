# Work across projects

One list of open tickets in a fixed work view (Needs me, Mine, Agents, Blocked or In review) across every project, grouped by project with a count, or for one project. Rows show the card's markers and open the ticket. First 50 projects and 200 tickets; the list says when it stops (AI-198, ADR-0108).

**How to use:** Header link Work (`/all/work`, or `/p/<project>/work`); pick a chip, Needs me by default. MCP `list_work` with `view` and an optional `project`.
