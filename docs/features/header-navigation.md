# Header navigation

Every screen has the same header. It holds the project picker and six destinations, Inbox first because that is where Andy decides: Inbox, Board, Roadmap, Work, Dashboards, and What's new when a project is picked. The quota gauge, "Needs you N" and a Settings menu (gear) sit on the right. The menu lists Project settings while a project is picked, then GitHub, Local runners, Models and Sign out. Each settings page has the same pages as tabs at its top. The digest is linked from What's new (AI-335).

On a phone the bottom bar shows Inbox, Board and Dashboards. More lists the remaining destinations and the settings pages in the same order.

**How to use:** click a destination, or the gear for settings; old URLs still open their screen
