# Keyboard shortcuts

Move through and act on the inbox and board without the mouse (AI-338). `j` / `k` step through inbox questions or board cards with a visible focus outline; `Enter` opens the focused ticket or chooses a focused answer; `a` focuses the question's answer field; `1`–`9` focus that answer (no single key answers anything); `g i`, `g b`, `g r` go to the inbox, board or roadmap in the current scope. Shortcuts never fire while you type in a field.

**How to use:** press `?` on any screen for the list; `Esc` closes it. The list and the rules for adding one: [`apps/web/design.md`](../../apps/web/design.md) "Keyboard".
