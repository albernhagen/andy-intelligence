# Agent tasks

Claude Code on GitHub Actions, locked down, Andy's subscription. Per-project dial (default 2, max 4), global cap 4, ≤5 agent PRs waiting, pause, quota reserve; the page and MCP `status` say why it idles (ADR-0079). Ready tickets whose `touches` overlap a build in flight wait, the next starts; In flight panel and MCP `list_in_flight` show tasks and files; each build reserves an ADR number (ADR-0080). Refine (read-only) on entering Up next: fills empty fields (risk, confidence with reasons) and reports, returns it to Ideas, or splits it (≤5 Ideas); asks only on an unsure or costly-to-reverse guess (3 open per ticket, `dailyQuestionCap` a day), else assumes ("Ask me instead" makes an assumption a question); costly gaps past a cap hold the ticket until asked or accepted (MCP accepts: AI-132); nothing to ask and Definition of Ready met (or last answer, or another pass): Ready. **Build** (off by default) takes the top Ready ticket: implements, sandbox-checks, PR with plan and verification; plan approval: Andy first approves a read-only plan, redone as blockers land. Unreported or failed tasks retry once, then Needs-you

**How to use:** Project settings: "Auto-refine", "Builds", "Auto-build", "Agent tasks at once", "Paused", "Plan approval"; MCP `set_runs_at_once`, `set_paused`; manual: ticket Activity or MCP `refine` / `build` ([runbook](../runbooks/agent-runs.md))
