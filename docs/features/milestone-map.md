# Milestone map

Each open epic's tickets from ticket data: done, in review with the PR, in progress, blocked and on what, not started; Needs-you marked; open tickets under no epic (AI-148). Each epic carries its `state` (ADR-0164); a waiting one says "waiting for your check". Replaces the hand-edited table in `docs/build-log.md`.

**How to use:** MCP `milestone_map` with `project`, optional `epic` key; `GET /api/projects/ai/milestone-map?epic=AI-84`
