# Tickets follow PRs

A project-repo PR naming a ticket (`AI-14` or its link) in its branch or first description line moves it from an open stage: opened into the default branch → Ready for review, merged → Done, closed unmerged → In progress + Needs-you; not fork PRs, drafts, epics

**How to use:** Key in the branch, or link first in the description ([runbook](../runbooks/mcp-connector.md) §4c)
