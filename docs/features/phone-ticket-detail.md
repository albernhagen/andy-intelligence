# Phone ticket detail

On a phone (390 px wide) a ticket fills the screen under the header with its status line first; the status wraps instead of being cut off, and Close is a 44 px target. Runs, activity and an agent task's page wrap long text (branches, links, reports) so nothing scrolls sideways (AI-175: M7.5: Phone ticket detail). Desktop layout is unchanged.

**How to use:** open a ticket on the board from a phone; tap an agent task in its activity for the task page.
