# Board work views

Chips above the board narrow it to one fixed view, each with its count of open tickets: Needs you (an open question, flagged, or a worker to pick; it counts tickets, "Needs you · 4 tickets", while the header counts things to answer, AI-326), Mine, Agents, Blocked and In review. The choice is in the URL, so a view can be linked; it combines with the epic filter, and cards still drag as usual (AI-187, ADR-0108).

**How to use:** On a project's board, click a chip; All shows everything again. Link straight to one with `/p/<project>?view=blocked` (`needs-me`, `mine`, `agents`, `blocked`, `in-review`).
