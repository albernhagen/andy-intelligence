# Dependabot updates

Weekly grouped PRs; npm patches (and minors of 1.0+ packages) auto-merge once checks pass; the rest wait for Andy. The review agents never run when Dependabot starts the run (no secrets); a minor or patch bump of manifests and lockfiles only also skips them when a person or bot starts the run (checks pass with the reason); Playwright gets its own PR, and the screenshot job fails, naming the fix, until its browser image matches (AI-394)
