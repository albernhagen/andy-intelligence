# Tickets

Projects; tickets move Backlog → … → Done/Cancelled by drag or buttons (Andy can force any move); a title suffices; type sets the Definition of Ready (spike: a findings doc), size the tier; tickets open over the board: status line, markdown, in-place edits, one timeline; archive hides finished ones. Backlog zones (drag or button): Up next (ordered, refined), Ideas (parked, no agent spend). Cards: size, risk, confidence; Ready sorts by them (`?sort=score`, rank unchanged) with why. Epics: an outcome line (ideate and refine propose it; refine never replaces one) and a "Done when" list, group, filter, stories, cost, cascading overrides, refine into stories with blockers. Cross-project blockers

**How to use:** Project (top left) → Board; REST under `/api`; in Claude, MCP tools for the same decisions, e.g. `ask_question` to ask one on a ticket (AI-290)
