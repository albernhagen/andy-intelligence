# Tickets

Projects; tickets move Backlog → … → Done/Cancelled by drag or buttons (Andy can force any move); a title suffices; type sets the Definition of Ready, size the tier; tickets open over the board: status line, markdown, in-place edits, one timeline; archive hides finished ones. Backlog zones (drag or button): Up next (ordered, refined), Ideas (parked, no agent spend). Cards: size, risk, confidence; Ready sorts by them (`?sort=score`, rank unchanged) with why. Epics: group, filter, stories, cost, cascading overrides, refine into stories with blockers. Cross-project blockers

**How to use:** Project (top left) → Board; REST under `/api`
