# Shell navigation and command palette

On desktop every screen has a left sidebar (AI-370): the project picker, six destinations (Inbox first, with its Needs-you count; Board, Roadmap, Work, Dashboards, and What's new when a project is picked), then the projects with their counts (on a settings page, the settings pages instead). At the bottom: the quota as one small meter per window (one quiet "Quota unknown" marker when there is no reading), "Search and commands" and the Settings menu (settings pages, theme, Sign out; ADR-0151). Cmd+K (Ctrl+K elsewhere) opens the command palette: it finds a ticket in the picked scope by key or title and runs every shortcut command, the theme switch, any page and a project switch. On a phone the header keeps the picker, quota, Pause and "Needs you N", and the bottom bar shows Inbox, Board and Dashboards; More holds the rest.

**How to use:** click or Tab through the sidebar; Cmd+K or "Search and commands", type, arrows and Enter; Esc closes
