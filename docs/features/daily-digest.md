# Daily digest

Exceptions first (failed tasks, PRs closed unmerged, rework, reverts, review blockers, tickets waiting on Andy or blocked, dispatch idle, quota at reserve), then merges (who, gate verdict, cost), in progress, totals (ADR-0081)

**How to use:** What's new in a project shows its exceptions first, with a 24 hours window (`/p/AI/digest` opens it; AI-341); MCP `digest` with `project`, optional `hours`, `until`; `GET /api/projects/ai/digest`
