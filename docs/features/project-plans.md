# Project plans

New projects' milestones wait in Needs-you and settings; approve: one epic each, in order, with the goal as its outcome and its Done-when lines, plus an approved milestone of the same name holding the plan's case (who it serves, expected return, cheapest test; ADR-0149) with the epic attached; reject: reason kept

**How to use:** Project plan card → **Start plan-project task**, or MCP `start_plan_project`, has an agent task write the plan; MCP `submit_project_plan`, `approve_project_plan`, `reject_project_plan`; then each epic's tickets: [epic breakdown](epic-breakdown.md)
