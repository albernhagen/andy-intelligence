# Project plans

New projects' milestones wait in Needs-you and settings; approve: one epic each, in order, with the goal as its outcome and its Done-when lines, plus a not-reviewed milestone of the same name holding the plan's case (who it serves, expected return, cheapest test; ADR-0149) with the epic attached: approve or park each on the roadmap before its tickets start; reject: reason kept

**How to use:** Project plan card → **Start plan-project task**, or MCP `start_plan_project`, has an agent task write the plan; MCP `submit_project_plan`, `approve_project_plan`, `reject_project_plan`
