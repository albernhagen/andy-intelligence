# What's new

Release notes and project status on one page: per milestone epic, tickets done, in review, in progress and not started, and what needs Andy; then every PR merged into the default branch, newest first, by day, one line each ("What changed", ticket, PR), opening to "How it works", "Needs you" and the feature file, ADR and runbook it touched. A PR without a note shows its title, marked "No note" (ADR-0121)

**How to use:** Header → What's new in a project (`/p/ai/whats-new`); filter by milestone, window 14, 30 or 90 days; MCP `whats_new` with `project`, optional `since`, `until`, `epic`; the digest links here. Every PR description carries the block (`release-note` check): `What changed:` (≤ 25 words), `How it works:` (≤ 45), optional `Needs you:` (≤ 25). Old PRs: [backfill runbook](../runbooks/whats-new-backfill.md)
