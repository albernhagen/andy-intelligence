# Project settings

Section links on the left (Setup, Automation, Limits, Defaults, Notifications, Changes; AI-372), one section beside them, picked by the URL hash (`#limits`). Merge mode is four cards, strictest to loosest (Manual, Per epic, Low risk, All clean), each with what merges and "You merge:" (what still waits for Andy); not set: no card picked, nothing merges, the old setting's mode marked "Suggested". Plan approval, default worker, default executor and environments show every option with a description, by name, never a raw value; on/off settings are switches. Each control saves on change and confirms there ("Saved", or the API's message). Builds only here (ADR-0063); merge mode loosened only here (ADR-0124). Setup: the plan card and the checklist (AI-95; "N left" on its link; unreadable repo: "unknown"), also over MCP `project_setup` (AI-287). Changes: every change with Revert, values by name.

**How to use:** Settings menu (gear) → "Project settings" (`/p/<project>/settings`, a section: `#setup`, `#automation`, `#limits`, `#defaults`, `#notifications`, `#changes`; `/projects` opens it); MCP `get_project_settings` and `project_setup` read, `set_*` change all but Builds (`set_merge_mode` only tightens; Questions per day: `set_daily_question_cap`)
