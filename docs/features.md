| Agent tasks            | Claude Code on GitHub Actions, locked down, on Andy's subscription; tasks at once per project on a dial (default 2, max 4), under a global cap (4), a cap on agent PRs waiting (5), a pause switch and the quota reserve; the page and MCP `status` say why dispatch idles (ADR-0079). A Ready ticket whose `touches` overlap a build in flight waits while the next one starts; the In flight panel and MCP `list_in_flight` list them with their files; each build reserves an ADR number (ADR-0080). Refine (read-only) starts when a ticket enters Up next, fills empty fields (risk and confidence with reasons) and comments a report, sends it back to Ideas, or splits it into at most 5 Ideas. It asks only when a guess would be unsure or costly to reverse (3 open per ticket, `dailyQuestionCap` a day); other guesses become assumptions ("Ask me instead" makes one a question). Costly gaps past a cap hold a ticket until asked or accepted (MCP accepts: AI-132). With nothing to ask and the Definition of Ready met, it goes to Ready, as does the last answer (or another pass). **Build** (off by default) takes the top Ready ticket: plans, implements, checks in a sandbox, opens a PR with plan and verification; with plan approval, Andy approves a read-only plan first. A watchdog checks unreported tasks; failures retry once, then flag Needs-you | "Auto-refine", "Builds", "Auto-build", "Agent tasks at once", "Paused", "Plan approval" in Project settings, or MCP (`set_runs_at_once`, `set_paused`); by hand: ticket → Activity, or MCP `refine` / `build` ([runbook](runbooks/agent-runs.md)) |
