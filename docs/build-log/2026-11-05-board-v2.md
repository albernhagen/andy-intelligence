# 2026-11-05 — Board v2 (AI-28)

AI-28: Board v2: status on cards, ordered Ready lane, reorder within a lane, quick add. Milestone M3: New UI and MCP.

- **Why:** Andy couldn't see status without opening tickets, and the order in a lane meant nothing (ADR-0059 row "Board", ADR-0058 row "Priority").
- **Cards:** type icon and key, title, then markers: size, "N questions" (or "Needs you"), "Refining · 1 min", "PR #62 · open", "Blocked by AI-4". Ready cards are numbered; the first unblocked one says "Next".
- **One read:** `GET /api/projects/{projectId}/board` returns each ticket with a summary (open question count, newest run in flight, latest `pr_linked` PR). Three reads per board plus one history read per card in In progress, Ready for review or Monitoring, capped at 50 (ADR-0028). No PR on Backlog, Ready or Done cards. Refetches every 5 s only while a run is in flight (the runs list's existing rule).
- **Reorder:** the ticket PATCH already accepted `rank`. `rankBetween` (`packages/domain/src/ranks.ts`) gives a rank between the new neighbours: the 10-digit number plus a decimal fraction ("0000000028.5"), so there is always room and no other ticket is rewritten. A drop across lanes moves the ticket, then ranks it at the drop position (two writes).
- **Optimistic:** a drop shows at once; a refusal puts the card back with the API's message on it. A drop still never opens the ticket (AI-25); the tests now click the card in its new lane, as a browser does.
- **Quick add:** "Add a ticket" at the top of Backlog; Enter creates a title-only ticket (no type). It replaces the "New ticket" form on the board.
- **Lanes:** Monitoring and Done start as strips with a count; Cancelled shows only with "Show cancelled and archived".
- **Not done:** PR check state ("checks running") — nothing records check runs yet; the marker shows the PR's state (open, merged, closed).
- **Open questions on AI-28:** refine asked five; this build followed the suggested answers except Q1 (a separate board read instead of widening the ticket list, so the list and MCP stay unchanged) and Q2 (client computes the rank with the shared domain helper; no new endpoint).
