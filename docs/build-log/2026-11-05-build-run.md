# 2026-11-05 — Build run: dispatcher, build step, PR (AI-3: M1.8a, first PR)

- **What:** a Ready ticket can now become a PR without Andy. `BuildDispatcher` takes the top Ready ticket by order (DoR met, blockers Done) on events only, in projects with `autoBuild` on (default off). The `build` run plans read-only, implements, runs the checks and returns plan, deviations and verification; a new `publish` job pushes `agent/<KEY>/<run>` and opens the PR `<KEY>: <title>` with the ticket link first. Decisions: ADR-0063.
- **Split:** AI-3: M1.8: Build + gate is three PRs: this one; `planApproval` (a read-only `plan` run approved before the build) next; then 8b (gate, auto-merge, metrics) as its own ticket.
- **Credentials:** the agent job still has no OIDC or write token. Bash runs only in Claude Code's sandbox (bubblewrap, registry-only network, credential variables unset, `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` for a PID namespace). The push token comes from `POST /github/token` through a new `TOKEN_POLICY` entry that gives one token per build run in flight.
- **Found on the way:** the PR review jobs run the PR's own `platform/actions/agent-review-*` and `scripts/review-*.mjs` while holding the Claude token (R5). Agent PRs may now be written without Andy, so those paths, and all of `.github/`, are Edit-denied and refused by the publish job. The catch-all CODEOWNERS `*` line no longer becomes an Edit deny (it would have denied every edit).
- **Not proven live yet:** the sandbox keys and the env scrub on Actions runners. Runbook `agent-runs.md` §9 has the probe (AI-12's deferred counted denial).
- **Tests:** a flow test drives the real API in-process: auto-build on → ticket to Ready → build dispatched on Opus (size M) → ticket In progress → context → one push token (a second refused) → report with PR → PR webhook → Ready for review. Plus dispatcher order, blockers, caps, retry with kept branch, foreign PR/branch rejection, profile and publish-check tests.
- **Also:** `ProjectPatch` is declared without defaults: with Zod's `.partial()`, patching one switch reset the other to its default.
