# Digest, 2026-11-10 evening to 2026-11-11: M2 built out, M3 nearly

For Andy. Covers every merge since the last section of [`2026-11-09-digest-m2.md`](2026-11-09-digest-m2.md).

## What changed, in plain words

- **Refine asks better questions.** Every question is a plain question with a quick view, then context, options and a recommendation (AI-73: Questions Andy can answer).
- **A costly open question no longer becomes a silent assumption.** When the question cap would drop it, the ticket is held in Up next until Andy answers or accepts it, in the UI or over REST (AI-75: Refine holds cap-demoted costly gaps). No MCP tool for accepting yet.
- **Andy can clear a stale quota reading** that is holding dispatch at the reserve (AI-74: Clear a quota idle).
- **Email for Needs-you items is built but off.** It sends through Resend, capped, once Andy adds the key (AI-77: Email notifications for the inbox).
- **Changes to agent rules are tested before merge.** A PR that edits a procedure, `AGENTS.md` or `.claude/` runs five review cases on the subscription and fails under a 90% pass rate or on a 20% input-token jump (AI-6: M1.17: Agent evals v1). Not yet seen on a live run.
- **Open pages update themselves.** Live views poll every 5 s, slow ones every 60 s, hidden tabs not at all, with an "Updates delayed" banner (AI-9: Live UI updates; polling, not push, ADR-0091).
- **One permission function** decides every "only Andy" rule and history records the acting user's id (AI-19: One permission function).
- **The local executor is designed**, not built: a runner on Andy's Mac polls the control plane (AI-44: Local executor, ADR-0089).
- **The coordinator now merges medium-risk PRs too**; Andy merges only what ADR-0092's list calls high (ADR-0088, ADR-0092). A tests-only change under a high-risk path is medium if it only adds cases or fixes flakiness.
- **Housekeeping:** the baseline ruleset file lists `firestore-suite` and R25 is closed (AI-76); two flaky tests fixed (AI-78); 13 minor and patch dependency bumps.
