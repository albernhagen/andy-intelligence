# 2026-11-21 — AI-322: UX deep dive: review the whole web UI

Andy asked for a deep dive on the UX. This entry is the review and the proposal; nothing is built. The proposals are tickets AI-325 to AI-343 under AI-84: M4: Epics + story board, all in Ideas, and none is started until Andy approves the list.

**How it ran:** a throwaway Playwright spec (not committed) rendered 22 screens at 1280×800 and at 390×844, plus the epic's night section, the agent task page and the project picker. It used CI's Docker image and the seeded fake API from `apps/web/e2e/fake-api.ts`, so production was never touched. Each screen was judged against `apps/web/design.md`, ADR-0070 (simple, minimal, biased toward deciding over operating) and the Hallmark trial's two rules: one primary per screen, and labels sit beside what they label. Screenshots are in [`assets/2026-11-21-ux-review/`](assets/2026-11-21-ux-review/).

**What this could not judge:** GitHub and Local runners return 404 from the fake API, so only their error state was seen. Dashboards with real agent-task data and a roadmap with many milestones come from the existing screenshot fixtures (`roadmap.png`), not from fresh renders.

## Overall

The bones are right. One shell, a decision-led inbox, status lines on cards, honest empty states and tokens only. Most of what gets in the way is accumulation:

- **Too many ways in:** nine header links, two of them settings and two of them reports of what happened.
- **Operating detail beside deciding detail:** the ticket rail, the board's In flight box and the agent task page.
- **Repeats:** quota shown twice on every screen, the same work under two names ("Needs you" and "Needs me") with two counts, and Ready shown both as a lane and as a page.
- **The phone layout breaks:** the board and the panels scroll sideways at 390 px.

## Ranked list

All of these are in Ideas under AI-84. Build order is top to bottom within each group, and quick wins are safe to start as soon as Andy approves. Anything the UI can do stays doable over MCP (AI-285); the removals keep their MCP tools.

### Quick wins (S)

1. **AI-325: Phone: no screen scrolls sideways.** The board and the panels are 837 px wide at 390 px.
2. **AI-326: Needs you: one word and one count everywhere.** "Needs me 4" against "Needs you 6".
3. **AI-327: UI text uses only project, milestone, epic, ticket and agent task.** "Stories", "runs", epics labelled as milestones, and a retired milestone line.
4. **AI-328: Quota is said once, in the header.** The banner shows only at warn or pause.
5. **AI-329: Times, durations and setting names read as words.** "17 days", not "25239 min"; no seconds; "Auto-refine: off → on".
6. **AI-330: Ticket panel: empty list fields fold into one Add row.**
7. **AI-331: Empty states say what to do next.** Roadmap, project plan, zero config proposals, empty dashboards.
8. **AI-332: Errors say what is missing, not "request failed (404)".**
9. **AI-333: Selected toggles use a quiet style, not filled black.** One shared segmented control.
10. **AI-334: Phone: 44 px targets on settings and the board's title row.**

### Larger changes (M)

1. **AI-335: Header: six destinations and an account menu.** Inbox, Board, Roadmap, Work, Dashboards and What's new, then a gear menu with Settings (tabs for this project, GitHub, Local runners and Models) and Sign out.
2. **AI-336: Ticket panel leads with the decision; epic panel with outcome, tickets and milestone.** One primary "next move"; Details; a collapsed "How it runs" group.
3. **AI-337: Phone board: one stage at a time.** Stage tabs with counts above one full-width lane.
4. **AI-338: Keyboard: move through and act on the inbox and board without the mouse.** `j`/`k`, `Enter`, `a`, `1`–`9`, `g i`/`g b`/`g r` and `?`.
5. **AI-339: Settings: grouped sections, one save model, labels beside values.** Automation, Limits, Defaults and Notifications.
6. **AI-340: Agent task page leads with its outcome.** A one-line summary, the PR and log first, and no empty rows.

### Things to remove (S)

1. **AI-341: Remove the Digest screen; What's new gets a Last 24 hours view.** MCP `digest` stays.
2. **AI-342: Remove the board's In flight box.** The cards and the Agents chip already show it. MCP `list_in_flight` stays.
3. **AI-343: Remove the Ready page; its filters move to the board's Ready lane.** MCP `list_ready` stays.

Overlaps: AI-327 covers UI text only; AI-205 (one glossary) covers docs. AI-341 is where AI-323's AI-written summary would show.
