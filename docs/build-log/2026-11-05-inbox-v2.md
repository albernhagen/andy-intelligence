# 2026-11-05 — Inbox v2: questions grouped by ticket, one-click answers (AI-30)

M3: New UI and MCP (epic AI-23). Why: the day auto-refine went live, the inbox held about 60 questions across 19 tickets in one flat list, and Andy asked for a URL for every page.

- **One card per ticket** (`components/inbox/InboxTicketCard.tsx`): type marker, key, title (links to the ticket), stage, then its open questions, or "Flagged for you" when it has none. Under All projects, a heading per project with its count.
- **Order** (`inboxCards` in `lib/needs-you.ts`): Backlog tickets whose only Definition of Ready gap is their questions (answering moves them to Ready), then tickets past Backlog, then other Backlog; ties by rank, then the most urgent question. Done, Cancelled and archived tickets go last under "Stale".
- **One click answers** (`InboxQuestion.tsx`): the suggested answer is the first button, marked "Suggested"; free text stays. "Accept all suggested (N)" answers the card's suggested questions one by one and stops at the first error, shown on the card.
- **Counts update at once**: `useAnswerQuestion` removes the answered question (and its ticket, once nothing on it is open) from the cached `/api/needs-you` before the refetch, so the header, page and group counts drop without a reload.
- **URLs**: `/` already redirected (replace) to the remembered scope's inbox (AI-26). Walked every shell screen; each has its own URL. `routes.test.tsx` loads each one directly.
- **Shared markers**: `components/TicketMarkers.tsx` (`TypeMarker`: lucide icon + type name; `StageBadge`) for the board and ticket page to reuse.
- **Screenshots**: the e2e seed gained a busy OPS project (four tickets, five questions, one Done); new `inbox-busy.png`; every image changed because the header count is now 6.
