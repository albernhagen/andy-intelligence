# Threat model: UI and MCP

Detail on browser sign-in, GitHub setup pages and the MCP endpoint. Risk register (every `R<n>` id), assets and mitigations: [threat-model.md](threat-model.md). PRs that change this area update this file; the weekly system review edits only the main file.

## Trust boundaries and entry points

| Entry point                                                                                                                                                | Who can reach it                              | Authn/authz                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Notes                                                                                                                                                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MCP endpoint `/mcp` and its OAuth server (`/.well-known/oauth-*`, `/oauth/authorize`, `/oauth/token`, `/api/oauth/approve`; consent page `/oauth/consent`) | Internet; meant for Claude (custom connector) | `/mcp`: our access token (hash lookup) + allow-list re-check per request; tools write as `andy` through `TicketService` and `RunService` (no delete, forced move or release; `promote_assumption` only opens a question, ADR-0075; `edit_ticket`, `comment_ticket`, `set_ticket_parent` and `reorder_ticket` stay inside one project: references to another project's tickets and blocker or parent cycles are refused, AI-40). Authorize/token: public, validate everything; approve: Firebase ID token + allow-list (ADR-0039) | Off unless `PUBLIC_URL` is set. Nothing is stored before approval. Client IDs fetched only from `claude.ai`/`claude.com` (R11). Body caps: `/oauth/token` 16 KB, `/mcp` 256 KB. All pages send `frame-ancestors 'none'` |
| GitHub setup `GET /api/github`, `GET /api/github/manifest`, `POST /api/github/connect`; pages `/settings/github`, `/settings/github/callback`              | Internet                                      | `/api/*`: Firebase ID token + allow-list. The manifest code is single-use and expires in 1 h; it appears in request logs (callback URL) but is spent by then                                                |

## Credentials and identities

| Identity / secret                     | Grants                                                                                                                                                                                              | Usable from                                                          |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| MCP OAuth codes and tokens (ADR-0039) | Code (60 s, single use, PKCE-bound): one token exchange. Access token (1 h): `/mcp` as Andy. Refresh token (30 days, rotated on use): new access tokens. Re-checked against the allow-list each use | Whoever holds them: Claude (Anthropic stores them for the connector) |

- **Worker (ADR-0082):** `PUT /api/projects/:id/tickets/:id/worker` and MCP `set_worker`, `set_default_worker`, behind the same allow-list as every other route and tool. They store a choice from a fixed list; `actor` is fixed to `andy`. Switching to an agent can start a build only under the existing `buildEnabled`, `autoBuild` and run caps. Agent runs can't reach them.
