# Threat model: UI and MCP

Detail on browser sign-in, GitHub setup pages and the MCP endpoint. Risk register (every `R<n>` id), assets and mitigations: [threat-model.md](threat-model.md). PRs that change this area update this file; the weekly system review edits only the main file.

## Trust boundaries and entry points

| Entry point                                                                                                                                                | Who can reach it                              | Authn/authz                                                                                                                                                                                                                                                                    | Notes                                                                                                                                                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MCP endpoint `/mcp` and its OAuth server (`/.well-known/oauth-*`, `/oauth/authorize`, `/oauth/token`, `/api/oauth/approve`; consent page `/oauth/consent`) | Internet; meant for Claude (custom connector) | `/mcp`: our access token (hash lookup) + allow-list re-check per request; tools write as `andy` through `TicketService` and `RunService` (no delete, forced move or release). Authorize/token: public, validate everything; approve: Firebase ID token + allow-list (ADR-0039) | Off unless `PUBLIC_URL` is set. Nothing is stored before approval. Client IDs fetched only from `claude.ai`/`claude.com` (R11). Body caps: `/oauth/token` 16 KB, `/mcp` 256 KB. All pages send `frame-ancestors 'none'` |
| GitHub setup `GET /api/github`, `GET /api/github/manifest`, `POST /api/github/connect`; pages `/settings/github`, `/settings/github/callback`              | Internet                                      | `/api/*`: Firebase ID token + allow-list. The SPA sends the code only if GitHub returns the `state` it kept in sessionStorage                                                                                                                                                  | One App per control plane: a second connect is `409`. The manifest code is single-use and expires in 1 h; it appears in request logs (callback URL) but is spent by then                                                |
| Firebase Auth (Google sign-in; authorized domain `ai.andybernhagen.com` only, plus `localhost` and `firebaseapp.com`)                                      | Internet                                      | Google account; authorized domains                                                                                                                                                                                                                                             | Web API key is public by design                                                                                                                                                                                         |
