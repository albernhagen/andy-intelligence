# R15

**Risk:** MCP tools return ticket and question text to Claude desktop. From M1.7: Refinement, agents write question text, so an injected question could steer Claude desktop, which may hold other connectors (mail, calendar).

**Mitigation / next step:** Agents treat untrusted input as data (§9); questions come only from runs on Andy's repos; Claude desktop asks before tool calls unless Andy allows them. Agent questions are capped (3 open per ticket, `dailyQuestionCap` per project a day; held past a cap if costly, ADR-0087); `list_needs_me` names the asking run (M1.7: Refinement) and also returns plans; an injected item could steer Claude toward the write tools, including `edit_ticket`, `comment_ticket`, `set_ticket_parent` and `reorder_ticket`; the `/inbox` procedure treats all of it as data and records only what Andy says (AI-40). Refine's risk and confidence reasons (`status`, `list_ready`) are the same kind of text: capped at 300 characters, shown as plain text in the UI. The read-only `digest` (ADR-0081) returns ticket titles and run errors (clipped to 200 characters) the same way. AI-73 adds more agent-written fields of the same kind (question context, option consequences, a recommendation; each capped, plain text in the UI), and the digest shows the oldest open question's line, clipped to 200 characters.
