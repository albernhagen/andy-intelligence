# R-AI-394

**Risk:** AI-394: Dependency bumps skip the review agents. A Dependabot PR that changes only `package.json` dependency versions and lockfiles, with no major bump, merges without the security or adversarial review agent reading it. A hijacked minor or patch release, or a PR that looks like a bump but changes behaviour through `package.json`, could reach `main` with no agent having looked.

**Mitigation / next step:** The skip needs the PR author to be `dependabot[bot]` (set by GitHub) and the whole change to pass `isDependencyBump` (`scripts/review-scope.mjs`): manifests and pnpm lockfiles only, nothing under `.github/`, `infra/`, `platform/` or `template/`, every other `package.json` field unchanged (no `scripts`, overrides or `packageManager`), no dependency added or removed, each version a plain version or `^`/`~` range with the same operator, within its major; the lockfile adds no package and resolves new versions only within a locked major (a transitive major runs the agents). Any other change, or a read failure, runs the agents; tests cover each case. Dependabot runs never had secrets, so the agents already skipped when Dependabot started a run; this extends the skip to runs others start (a re-run, a re-sync merge) on an unchanged bump. Still on every bump: 7-day cooldown, CI with the lockfile-sources check (npm registry and integrity only), dependency review, CodeQL, secret scan; majors wait for Andy (ADR-0042). The skip rule lives in `scripts/` and `platform/actions/`, so a PR changing it is reviewed (not a bump) and `platform/actions/**` is Andy's to merge. Next: epic AI-154: Dependency agent.
