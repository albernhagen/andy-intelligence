# R19

**Risk:** A leaked control-plane App key writes contents and pull requests on every repo it is installed on; a forged Actions OIDC token or too-wide `TOKEN_POLICY` would too.

**Mitigation / next step:** Key only in Secret Manager, read and versioned by the runtime SA alone; App private to Andy, installed only on project repos, no `workflows` permission; `main` requires PRs; OIDC tokens checked for issuer, audience, signature, expiry, repository and `workflow_ref` (incl. branch); policy changes need a PR; rotation in `docs/runbooks/github-app.md` §6. It can also start or cancel runs; run callbacks still need the executor's OIDC token. AI-122: it creates `epic/<KEY>` once per launch, refused if it exists.
