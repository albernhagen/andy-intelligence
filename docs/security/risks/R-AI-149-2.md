# R-AI-149-2

**Risk:** A Claude Code cloud worker acts as Andy through the `andy-intelligence` connector and the Claude GitHub App. Injected ticket or PR text could steer it to answer a question, approve a plan or move a ticket as Andy, or to push a harmful branch.

**Mitigation / next step:** Every branch still passes CI, both review agents and ADR-0120's "Andy keeps" rules; the environment holds no secrets, so a compromised VM holds only the session's own access; network "Limited". Residual: package-manager hosts stay reachable, so data could leave in a request to one. Observed in AI-151: Prove a cloud worker end to end and fix the runbook to match (2026-11-26): the session held every `andy-intelligence` tool, write tools included, and Andy's other connectors (Gmail with send, Calendar, Drive, Docs, Sheets, Hevy); whether a first call asks Andy is not visible to the worker. Next step: Andy decides which connectors cloud workers get. Area: [`coordinator-and-cloud-sessions.md`](../coordinator-and-cloud-sessions.md).
