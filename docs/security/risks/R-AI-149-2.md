# R-AI-149-2

**Risk:** A Claude Code cloud worker acts as Andy through the `andy-intelligence` connector and the Claude GitHub App. Injected ticket or PR text could steer it to answer a question, approve a plan or move a ticket as Andy, or to push a harmful branch.

**Mitigation / next step:** The connector asks for approval before its first call _(untested)_; every branch still passes CI, both review agents and ADR-0120's "Andy keeps" rules; the environment holds no secrets, so a compromised VM holds only the session's own access; network "Limited". Residual: package-manager hosts stay reachable, so data could leave in a request to one. Open until AI-151 records what the App and the connector can do. Area: [`coordinator-and-cloud-sessions.md`](../coordinator-and-cloud-sessions.md).
