# R-AI-406

**Risk:** AI-406: Screenshot checks: no animation while capturing, and skipped on PRs that cannot change the web app. `ui-screenshots` passes without running when the gate judges that no changed file can affect the web app. A wrong path list, or a PR that weakens the gate, would let a UI regression merge with the required check green.

**Mitigation / next step:** The gate defaults to running: a path skips only when it is on an explicit can't-affect list and not under the app, a workspace package it imports, `platform/baseline`, root install config or the check's own files. Tests rebuild the app's workspace-dependency closure from the `package.json` files and scan relative imports leaving those packages, so a new dependency fails `pnpm test`; unknown paths, unreadable diffs, renames and deletions run. The action runs without asking the gate when the gate, image check, action or workflow changed. `platform/actions/**` is Andy's to merge (ADR-0120). Every push to `main` runs the full suite, so a missed regression shows on the next merge.
