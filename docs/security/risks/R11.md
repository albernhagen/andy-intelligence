# R11

**Risk:** `/oauth/authorize` fetches the client ID metadata document named in an unauthenticated request (SSRF, outbound cost).

**Mitigation / next step:** Fetch only HTTPS URLs on `claude.ai`/`claude.com`, no port, no redirects, 5 s timeout, 16 KB cap, 1 h cache of ≤ 20 clients, failures cached 1 minute, ≤ 30 fetches/minute per instance; max 2 instances (ADR-0028).
