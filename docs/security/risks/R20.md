# R20

**Risk:** Whoever controls DNS for `andybernhagen.com` (Cloudflare account, the DNS token, the registrar) can point `ai.andybernhagen.com` elsewhere and get a certificate for it: they'd receive Google sign-ins, MCP OAuth codes, webhook deliveries and Actions OIDC tokens, replayable to the real service within their lifetime for a repo write token.

**Mitigation / next step:** Cloudflare 2FA and registrar lock (runbook `custom-domain.md` §1); DNS token scoped to one zone, expiring, kept in the keychain; `infra/dns` applied only from Andy's machine.
