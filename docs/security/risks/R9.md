# R9

**Risk:** The system review runs an agent over the whole repo (untrusted text) with `CLAUDE_CODE_OAUTH_TOKEN`; its edit ends up in a PR opened with an App token whose checks run on their own.

**Mitigation / next step:** Agent tools limited to Read/Glob/Grep, Edit of existing `docs/security/*.md` files (AI-76) and Edit or Write of `docs/security/risks/*.md` files (AI-144, ADR-0109); no Bash; agent job has `contents: read` and no `id-token: write`; CI rejects any other change, a deleted file, a malformed risk file or a newly `accepted` risk; `publish` job (no Claude token) takes only those files, gets the repo token and pushes a new `security/` branch; the App can't touch workflow files; Andy merges the PR.
