# R-AI-201-4

**Risk:** AI-201: M6.16: Project environment module, with `promote_source_repository` set on prod (`dev-and-prod`), gives prod's Cloud Run service agent read on the dev registry repo so promote ships the verified digest. It is the one cross-environment grant: an image pushed to the dev repo by the dev main deployer can be deployed to prod by the prod main deployer.

**Mitigation / next step:** Read-only, on one repo, for Google's service agent only; no runtime or deployer identity gets cross-project access. Only the dev main deployer and, to tag `release-*`, prod's main deployer (both main-only, R-AI-201, R-AI-389) can write that repo, and promote passes a digest from a succeeded, verified dev deployment (ADR-0114), never a tag, so a later push can't change what is promoted. Off unless set.
