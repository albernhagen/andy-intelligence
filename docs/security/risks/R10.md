# R10

**Risk:** Managed repos run composite actions from this public repo with their own tokens and secrets (`CLAUDE_CODE_OAUTH_TOKEN`, `pull-requests: write`). A malicious change merged here and pinned by a managed repo runs there.

**Mitigation / next step:** SHA pins (a moved tag can't change them); updates only by Dependabot PRs (7-day cooldown) that Andy merges; this repo's own PRs pass the same reviews. Add CODEOWNERS on `platform/` when collaborators join.
