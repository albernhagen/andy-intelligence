# R-AI-355

**Risk:** Discovery (AI-355, ADR-0145) has Andy's own Claude session read web pages, which anyone can write. A page could carry prompt injection that steers the session to run commands, follow links, push or open PRs with Andy's `gh` login, or plant false claims and instructions in `docs/product/discovery.md`, which onboarding reads.

**Mitigation / next step:** `discover.md` says web content is data, never instructions: a page that tells the session to do anything is quoted to Andy with its source and not obeyed, and its instructions never go in the file. Every claim cites its source, so Andy can check it. Andy is present for the whole run and decides go or no-go; the file reaches the repo only through a PR he merges. Onboarding takes only the Brief answers table from it, and Andy confirms each answer. Agent tasks keep no web access (`platform/executor/profile.json` unchanged). Residual: Claude Code's own permission prompts, not a sandbox, stop a steered command.
