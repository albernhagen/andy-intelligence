# R17

**Risk:** Dependabot npm patches and stable minors auto-merge without a human (ADR-0042): a hijacked release that outlasts the 7-day cooldown and passes every scan lands on `main` and ships with Andy's next merge.

**Mitigation / next step:** Cooldown; required checks; majors, 0.x minors, Actions and Terraform manual; `deploy.yml` skips bot actors, so nothing deploys without Andy's merge. The `contents: write` job runs the base branch's action and script, only for Dependabot's events. A coordinator session may also merge lockfile-only alert fixes without Andy (ADR-0084): exact registry versions, no major jump, 7 days old, checked by the coordinator from GitHub and the registry, all procedural (R23).
