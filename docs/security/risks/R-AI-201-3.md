# R-AI-201-3

**Risk:** AI-201: M6.16: Project environment module creates runtime identities `<service>-run` and `<service>-pr-run` per environment. Too broad a role, or a role in another environment's project, would let a compromised app (or, for the preview, any PR) reach data or resources beyond its own environment, e.g. dev code reading prod data.

**Mitigation / next step:** Each identity lives in its environment's GCP project, and every grant is a project role in that same project: logs and traces for both, plus `runtime_project_roles` for the main one only. The module refuses owner, editor, `iam.*`, `resourcemanager.*` and `*.admin` roles there. Nothing grants a runtime identity anything in another project, and dev and prod are separate projects (ADR-0050). Cross-project image reads for promote go to the Cloud Run service agent, not a runtime identity (R-AI-201-4).
