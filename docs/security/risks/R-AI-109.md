# R-AI-109

**Risk:** AI-109: M6.22: Deploy scaffold for new projects keeps a `cloud-run` project's Terraform state in `gs://<prod project>-tfstate`. State holds the real project IDs, the billing account ID and the alert email (personal data), and versioning keeps old copies. Anyone who can read the bucket reads them.

**Mitigation / next step:** The bucket is created with uniform bucket-level access and public access prevention, so it can't be made public; readers are only the prod project's members. Versioning keeps the last 10 old versions (lifecycle rule), so old copies expire. Andy creates it by hand with his own login (runbook `project-env.md`); no CI or deployer identity is given access. The repo holds only fake example values (a test checks); real ones stay in the gitignored `infra/terraform.tfvars`.
