# R-AI-276

**Risk:** The global spend caps (AI-276: M10: Global spend caps store and editing) are the ceiling for every project. A mistaken raise lifts what every project may spend once paid routes are live, and a store that can't be read would, if it fell back to the defaults, hide that the caps are unknown.

**Mitigation / next step:** owner-only writes (`change_spend_caps`); whole micro-dollars only; each save is checked against the version read (a stale save is a 409) and logged as a global ConfigChange, revertable from Settings → Models or MCP. An unreadable store never reads as the defaults: the spend gate refuses every paid task and no project cap is saved. Before AI-269: M10.18 (first paid task), Andy sets the global caps he wants.
