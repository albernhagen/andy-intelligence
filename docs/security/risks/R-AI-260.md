# R-AI-260

**Risk:** The `claude-api` provider (AI-260: M10.13) spends Andy's money through `ANTHROPIC_API_KEY`. The agent's `--max-budget-usd` is a soft cap: Claude Code checks it between turns, so one long turn can spend past the run's reservation. Until the Anthropic Console workspace limit exists, nothing outside the control plane stops it.

**Mitigation / next step:**

- Off by default; no model has a price yet, so the spend gate refuses every paid start (fail closed).
- The workflow refuses a credential that doesn't match the run's billing, caps the budget at $50 and gives helper calls $0.25; the local runner refuses pay-per-use runs.
- Settling records the real cost in full, so an overshoot counts toward the day and month caps.
- Before turning `claude-api` on: Andy sets the Console workspace limit at or below the monthly cap (AI-267: M10.16).
