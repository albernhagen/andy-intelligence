# R-AI-113

**Risk:** Registering a repo makes the control-plane App commit files to a new branch in it and open a PR (ADR-0142). A bug, or someone who can register repos, could use that to push unreviewed CI, agent settings or code into a managed repo, or overwrite a file the project changed on purpose.

**Mitigation / next step:** Only the owner registers projects (`register_project`). The App commits only to a new `baseline/<sha>` branch and never merges: Andy reviews and merges the PR. File contents come from `andy-intelligence` at `main`'s tip, never from agent or webhook text. Only missing files are written; a differing one is reported. `BaselineProposal` refuses `.github/workflows/**`, `.claude/**`, `..` paths and more than 40 files; the App has no `workflows` or administration permission. Settings reads are GET-only, inside the repo, with checked paths; values quoted from the repo render as code, and Needs-you tickets mark them as data. At most 3 repos per registration, each within 40 s and capped reads. Failures go to Needs-you, never retried in a loop.
