# R-AI-393

**Risk:** A project logo is a file the owner uploads, from the web or over MCP, and the web shows it on every page. A hostile SVG (a script, an event handler, an external reference) could run code in the app or leak who viewed it, and a huge file could bloat every page.

**Mitigation / next step:** Owner only; SVG at most 64 KB or PNG at most 128 KB; every SVG is parsed and rebuilt from an allowlist, refusing scripts, handlers, external references and importing CSS; PNGs must carry the signature. The web renders a logo only as an `<img>` from a data URL, which runs no script and loads nothing, and fetches it only when `logoUpdatedAt` changes. The follow-up that copies a logo into a project's repo reviews this risk. Detail: `project-logos.md`.
