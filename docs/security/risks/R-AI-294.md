# R-AI-294

**Risk:** A stolen MCP token reads runner metadata over `list_runners` (ADR-0135): runner names, project ids, who registered each, expiry, last seen and presence, so a thief learns when Andy's Mac is online.

**Mitigation / next step:** Read-only and secret-free (`RunnerView` carries no secret or hash; the parity test checks the MCP text). Minting has no MCP tool; revoking (owner only) is ADR-0143, risk R-AI-351. MCP tokens: 1-hour access, allow-list re-checked on every use (ADR-0039). An owner check for the route and the tool together comes with AI-18: Project members.
