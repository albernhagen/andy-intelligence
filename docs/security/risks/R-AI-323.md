# R-AI-323

**Risk:** The `summarize` task (AI-323) reads untrusted text (PR titles, release notes, ticket and epic titles). Injected text could steer it to a misleading summary at the top of the digest, such as claiming something shipped that didn't.

**Mitigation / next step:** `digest-summary.md`: no tools at all, so a steered agent can only change its own answer. Untrusted text is JSON-escaped after fixed text. The output is schema-checked twice, and every citation must be in the input. It is shown as model-written plain text above the computed list it summarizes. One write per project per day, under a daily cap.
