# R-AI-162

**Risk:** AI-162: M6.14: Project budget module can put a cost kill switch in each managed project's GCP project. Its `budget-notifications` topic is a DoS lever (a fake message at ≥150% takes that project's service offline), and its `cost-kill-switch` identity can update that one Cloud Run service and act as its runtime identity, so whoever controls the workflow could change the service's revision.

**Mitigation / next step:** Off by default; Andy turns it on per entry and applies `infra/billing` himself (ADR-0029). Grants are in the managed project only: Cloud Run on the one named service, actAs on the one runtime identity, queue list/pause and operation reads at project level; nothing in the control-plane project. The workflow's code is fixed in Terraform, and only Cloud Billing plus that project's `pubsub.publisher` holders can publish. The module refuses to run without a named service and runtime identity, and `infra/billing` refuses the control-plane project as a managed entry.
