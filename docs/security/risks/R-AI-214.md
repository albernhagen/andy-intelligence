# R-AI-214

**Risk:** The merge mode (ADR-0124) will decide which PRs merge without Andy. Anyone who can loosen it, or a ticket or epic override that ends up looser than its project, widens what merges unreviewed. Since AI-215 the gate merges by it (`mergeVerdict`); a project with no mode saved merges nothing (ADR-0134).

**Mitigation / next step:** Owner only (`change_project_settings`). Loosened only on the settings page: MCP `set_merge_mode` and settings reverts over MCP may only tighten it (unset counts as `manual`); `set_auto_merge` is gone. Every change is in the config change log. Overrides may only be stricter when written, and `effectiveTicketMergeMode` takes the stricter of project and override, so a project tightened later still wins; AI-216 (epic mode) must read a ticket's mode through it. Detail: `project-settings.md`.
