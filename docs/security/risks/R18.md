# R18

**Risk:** `/webhooks/github` is public: unsigned floods cost CPU; a captured signed body replayed under new delivery IDs (unsigned) repeats records and ticket moves; deliveries lost to an outage aren't retried.

**Mitigation / next step:** Body cap 1 MB; signature before the rate cap (≤ 300 signed/minute per instance) and before any Firestore access; Cloud Run caps, alerts and the kill switch bound cost. Consumers re-read GitHub state and dedupe.
