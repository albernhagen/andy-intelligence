# R-AI-351

**Risk:** A stolen MCP token revokes Andy's local runners over `revoke_runner` (ADR-0143): his Mac stops claiming `local` tickets until he registers a new runner in the app. A denial of service on the local executor only; no secret is created or shown.

**Mitigation / next step:** Owner only (`revoke_runner`, checked in `RunnerService.revoke`, same as the route), and each revoke logs "runner revoked" with the actor. Minting has no MCP tool, so a thief can't replace the runner with their own. MCP tokens: 1-hour access, allow-list re-checked on every use (ADR-0039). Recovery: register a new runner (Settings → Local runners).
