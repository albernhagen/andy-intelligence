# R6

**Risk:** Prompt injection in a diff could make the reviewer under-report. Replies and the PR body reach both reviewers too; the implementing agent posts as Andy, so its text looks owner-authored.

**Mitigation / next step:** Read-only tools, structured output, deterministic scans, a coordinator merges clean PRs unread (ADR-0120, R23); different-vendor reviewer from M9: Add Jules + model routing. Docs-only PRs skip the agent: text planted in `docs/` for future agents is caught only by the coordinator's own diff read (R23); agent rule files are always reviewed. Reviewers treat discussion as context only: a blocker or security finding clears only when the code changes (ADR-0037).
