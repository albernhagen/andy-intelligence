# R-AI-149

**Risk:** `resync` (`scripts/coordinator/resync.mjs`) runs a PR branch's code as Andy. A prompt-injected worker could change `lefthook.yml`, a test or a typecheck config so the pre-push hook runs its code during the coordinator's push. With no tokens in the environment it can still reach Andy's keychain GitHub login.

**Mitigation / next step:** Built (AI-149): install runs with `--ignore-scripts`, the budget check is `main`'s copy, and install, checks and push run with GitHub, cloud and secret-named variables removed from the environment. The same code already runs as Andy when the worker itself pushes from the same Mac. Next: push from a separate macOS user or a container holding only a push token, or have the coordinator review the branch's hook and config diff before `resync`. Area: [`coordinator-and-cloud-sessions.md`](../coordinator-and-cloud-sessions.md).
