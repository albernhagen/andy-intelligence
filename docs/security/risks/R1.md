# R1

**Risk:** `tf-plan` has basic Viewer (likely reads Firestore documents and most logs) and federates from **any** branch and event in this repo. A workflow on a pushed branch can read data with it.

**Mitigation / next step:** Replace `roles/viewer` with the narrow viewer roles plan needs; restrict the WIF binding (e.g. `assertion.event_name` in `pull_request`, `workflow_dispatch`, `schedule`).
