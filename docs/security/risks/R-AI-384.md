# R-AI-384

**Risk:** MCP `reserve_adr_number` lets a session with Andy's grant take ADR numbers. A session that loops could burn through the four-digit sequence or fill the project's holds so other sessions are refused; a stale hold could hand two PRs one number if numbers were ever reused.

**Mitigation / next step:** Owner only (`requireCan`), and project access on the `ticket` field before the tool runs (`withProjectAccess` in `apps/api/src/mcp/tools.ts`), like every MCP tool. 5 open holds per ticket and 20 per project, checked in the same transaction as the counter (ADR-0028); holds end when the ticket's PR into the default branch merges or closes (signed webhook) or after 7 days. Numbers are never reissued, so a release can't cause a clash; the cost of a loop is gaps, at most 20 numbers per project until holds end. Every reservation and refusal is logged (`adr-numbers`). Detail: `coordinator-and-cloud-sessions.md`.
