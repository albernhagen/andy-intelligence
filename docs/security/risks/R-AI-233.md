# R-AI-233

**Risk:** Jules executor (AI-233): a leaked Jules API key starts tasks on Andy's Jules plan, using its daily limit, and Jules pushes branches and opens PRs in every repo its GitHub app is installed on.

**Mitigation / next step:** Key in Secret Manager (`jules-api-key`), readable by the runtime service account only; version added by Andy, never in the repo, state or CI. The app is installed only on chosen repos; a Jules PR reaches `main` only through its ruleset (required checks and reviews). Rotate or revoke: runbook `jules.md`.
