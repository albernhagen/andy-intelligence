# R-AI-233

**Risk:** Jules executor (AI-233): a leaked Jules API key starts tasks on Andy's Jules plan, using its daily limit, and Jules pushes branches and opens PRs in every repo its GitHub app is installed on.

**Mitigation / next step:** Key in Secret Manager (`jules-api-key`), readable by the runtime service account only; version added by Andy, never in the repo, state or CI. The app is installed only on chosen repos; a Jules PR reaches `main` only through its ruleset (required checks and reviews). Rotate or revoke: runbook `jules.md`. No code uses the key yet; the caps arrive with its first user: AI-240: M9.10: Jules executor adapter starts tasks under the run caps (ADR-0079), and AI-232: M9.5: google-sub quota by task counting pauses Jules at the plan's daily task limit (ADR-0028).
