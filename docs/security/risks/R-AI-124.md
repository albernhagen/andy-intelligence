# R-AI-124

**Risk:** Overnight, the control plane squash-merges story PRs into `epic/<KEY>` with its App token (AI-124, ADR-0107): a story merged overnight is Done before Andy reviews it, and later stories build on it, so a bad early story taints the rest.

**Mitigation / next step:** `night-runs.md` ("Merging into the epic branch"): same merge gate except `autoMerge`, only into the launch's recorded epic branch, `epic/<KEY>` refs only, ≤ 50 merges per launch; the morning PR into `main` is Andy's to merge.
