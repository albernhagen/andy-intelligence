# R-AI-124

**Risk:** Overnight, the control plane squash-merges child-ticket PRs into `epic/<KEY>` with its App token (AI-124, ADR-0107): a ticket merged overnight is Done before Andy reviews it, and later tickets build on it, so a bad early ticket taints the rest.

**Mitigation / next step:** `night-runs.md` ("Merging into the epic branch"): same merge gate except the merge mode, only into the launch's recorded epic branch, `epic/<KEY>` refs only, ≤ 50 merges per launch; the morning PR into `main` is Andy's to merge.
