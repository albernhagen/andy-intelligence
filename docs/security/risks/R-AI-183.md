# R-AI-183

**Risk:** Releases read (AI-183: M6.9). A signed-in route and MCP tool return release-note and commit text written by PR authors, and the first listing of a project can start up to 100 code-host compares. A release is kept on its deployment for good, so a note stored later (a backfill) or a wrong code-host answer is never corrected for that release.

**Mitigation / next step:** Project-access check before any read (`404`, never `403`); read-only besides one cached release per deployment, written only when no release is kept yet; text is plain text and the tool labels it data, never instructions; caps: 100 deployments, `limit` compares 5 at once and none once kept, `unavailable` never kept. If a kept release must be refreshed, a later ticket adds a way to clear it. Detail: `releases.md`.
