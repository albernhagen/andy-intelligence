# R-AI-344

**Risk:** The `context-budget-trim` job (AI-344, ADR-0138) holds the job's `GITHUB_TOKEN` with `issues: write` on every push to `main`. A bad change to its workflow, action or script could create, edit or close issues in the repo; a file path in the issue body comes from the repo.

**Mitigation / next step:** Runs only on pushes to `main` (`if:` on event and ref), on `main`'s own checkout: no PR code runs in it, and changing it needs a merged PR. The token is GitHub's per-job token (expires with the job), `contents: read` and `issues: write` only, no stored secret. It edits only an open issue opened by `github-actions[bot]` whose body starts with its marker. Caps: one issue, at most 3 pages of open issues read. Detail: `entry-points-and-credentials.md`.
