# R-AI-249

**Risk:** Spend caps settings (AI-249: M10.8) let the owner raise a project's cap up to the global cap, and the global caps are code constants until AI-276: M10: Global spend caps store and editing. A mistaken raise, or caps left at the defaults when Andy meant lower, would let paid tasks spend up to the global caps once the spend gate (AI-248: M10.7) and a paid provider are live.

**Mitigation / next step:** owner-only writes (`change_project_settings`); a project cap above global is refused on every write path; every change is in the config change log and revertable; spend reads "unknown", never zero, when the ledger can't be read. Before AI-269: M10.18 (first paid task): AI-276 lands, and Andy sets the caps he wants.
