# R-AI-268

**Risk:** The weekly model scout is a new public route (`POST /jobs/model-scout`) and reads a third-party list (OpenRouter's models). A forged call could flood Andy's inbox with proposals or trigger fetches; a hostile or huge list could exhaust memory or steer a proposal toward a bad model.

**Mitigation / next step:**

- Built (AI-268: M10.17): the route accepts only a Google OIDC token for the `scout-scheduler` service account (audience `PUBLIC_URL`), then ≤ 6 calls an hour per instance; absent until configured.
- At most one pending change per ISO week (dedupe key, checked before the fetch), never applied: Andy accepts or rejects it.
- The list is fetched without a key (15 s, 5 MiB, no redirects), parsed and bounded by `parseModelList` (AI-237), never logged. Outcomes outrank price: a swap needs 5+ finished tasks on both models.
- Research sentences come only from a `direct` call (off by default) behind the spend gate; they are labelled model-written in the reason and never change the diff.
- The week is claimed before any paid call: only the call whose pending change is created researches, then appends to its reason (`appendReason`, pending only). Research runs only under an existing project (`ai`), else it is skipped and logged.
- Severity: low (proposal only, no spend by default). Status: mitigated.
