# R-AI-348

**Risk:** The review agents now run, holding the Claude token, on runs a bot starts: the control-plane App's pushes to agent PRs (ADR-0141). Scoped too widely, any App could start agent runs on content it controls. Scoped too narrowly, agent PRs, the ones that can merge on their own, would go unreviewed.

**Mitigation / next step:** `allowed_bots` is set per run by `agent-review-prepare`. It is the App's login only when `github.actor` is that App and the head branch starts with `agent/`, and `""` for every other run, which stays refused and fails its check (ADR-0140). Never `'*'`. The agent keeps Read/Glob/Grep only and treats the diff as untrusted data. The job runs no PR code, and agent builds can't change `.github/` or the review scripts (R2). Tests cover the App on `agent/*`, the App elsewhere, other bots, people, and an unset `agent-bot`.
