# R14

**Risk:** Public `/mcp` and `/oauth/token` cost a Firestore read per token-shaped guess (cost abuse), and the cap that bounds it can be exhausted to lock Andy out of MCP (DoS).

**Mitigation / next step:** Malformed tokens rejected without a lookup; ≤ 120 lookups/minute per instance × 2 instances ≈ $0.20/day worst case (ADR-0039); Firestore usage alerts and the kill switch. A lockout lasts only as long as the flood; UI, API unaffected.
