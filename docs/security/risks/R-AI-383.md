# R-AI-383

**Risk:** A plan-epic agent task (AI-383) reads untrusted text: the epic, its milestone's case, its children's titles, Andy's note and the repo. Injected input could steer it to draft misleading tickets, such as acceptance criteria that ask a later build to weaken a check. Andy might approve them without noticing.

**Mitigation / next step:** see `project-tasks.md`. The start is owner-only. The task has read-only tools on the cloud executor. Untrusted text is JSON-escaped in one block after fixed prompt text. Every result passes the contract schema: capped fields, at most 12 tickets, never an epic, no blocker cycle. `requireOwnEpicTask` means only the epic's own run can record a breakdown. Caps: one task per epic in flight and 3 in all. Each drafted ticket is shown to Andy before anything is created. Approved tickets land in Ideas, where nothing builds, and refine and build treat ticket text as untrusted data.
