# R-AI-397

**Risk:** Backward moves over MCP (AI-397: MCP move_ticket: allow backward moves; forward stays one step, ADR-0163). Any holder of an MCP token, or a session misled by untrusted text, can move open tickets back any number of stages: pull work out of review, or send many tickets to Backlog. It undoes progress and could orphan an agent task or a PR.

**Mitigation / next step:** Forward stays one step with the DoR checked, so nothing skips review or a gate. Moves out of Done or Cancelled stay owner-only in the web app. A backward move is refused while an agent task is queued or running or the latest PR is open. Every move is a `stage_changed` event with the actor, unforced; Andy can move a ticket forward again. Moving back to Backlog lands in Ideas and starts no agent task. MCP tokens are allow-listed (ADR-0039). Detail: `ui-and-mcp.md`.
