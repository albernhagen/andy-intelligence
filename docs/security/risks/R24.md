# R24

**Risk:** Quota readings come from the run report (M1.9: Quota capture), so a compromised run could write a false level.

**Mitigation / next step:** Fresh (under 6 hours) readings: pause stops dispatch, warn allows one task (ADR-0079, ADR-0100). Reports are checked on write (reset range, same window, no large drop), so a false low is limited; a false high holds dispatch visibly ≤ 6 hours per report, and Andy can clear a pause sooner (AI-74: owner only, once per reading, with who and when in the digest; not warn); the next reading skips only the drop check. The run caps bound the rest. Units' live check open (`docs/runbooks/quota.md`).
