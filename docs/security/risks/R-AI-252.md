# R-AI-252

**Risk:** Once members exist, a route or tool that skips the project check, or reads a second ticket key it doesn't check, shows a member another project's tickets (AI-252).

**Mitigation / next step:** One check on `/api/projects/{p}/*`, `/api/tickets/{KEY}` and every MCP project or ticket-key input, 404 on refusal; registry tests fail on an unchecked route, tool or key field. Open until M8.5 checks API body keys and makes the check required, and M8.7 filters the cross-project list: `project-access.md`.
