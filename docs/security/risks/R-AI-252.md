# R-AI-252

**Risk:** Once members exist, a route or tool that skips the project check, or reads a second ticket key it doesn't check, shows a member another project's tickets (AI-252).

**Mitigation / next step:** One check on `/api/projects/{p}/*`, `/api/tickets/{KEY}` and MCP `project`/`ticket` inputs, 404 on refusal; a registry test fails on an unchecked, unlisted route or tool. Open until M8.5 checks other key inputs and M8.7 filters the cross-project list: `project-access.md`.
