# R-AI-252

**Risk:** Once members exist, a route or tool that skips the project check, or reads a second ticket key it doesn't check, shows a member another project's tickets (AI-252).

**Mitigation / next step:** One check on `/api/projects/{p}/*`, `/api/tickets/{KEY}`, the project and ticket keys in `/api` write bodies and in every MCP input; 404 on refusal. Routes and tools naming no project are refused unless listed as cross-project (fail closed), and registry tests catch them first. Open until M8.5 makes the access rule required and M8.7 filters the cross-project list: `project-access.md`.
