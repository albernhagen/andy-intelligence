# R-AI-301

**Risk:** Milestone status decides what dispatch and coordinator sessions may start (ADR-0131: Milestones, proposed). Sessions call MCP as Andy, so a session misled by text in a ticket, page or log could approve a parked milestone and start agent work, and spend, that Andy did not choose.

**Mitigation / next step:**

- Planned: writes are owner-only and never in an agent task's tools (AI-304: M4.34); each change is a config change with who and when, shown in the audit view and revertable (AI-118); spend stays under the existing dispatch and spend caps (ADR-0028).
- Open: question 3 on AI-301 asks whether MCP may approve or only park.
