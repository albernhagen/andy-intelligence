# R-AI-250

**Risk:** The OpenRouter adapter spends money on each call and sends prompts to a third party. Called outside the spend gate, it could spend past the caps; a logged key or request would leak the key or project text; a hostile or huge response could exhaust memory or steer the step that reads it.

**Mitigation / next step:**

- Built (AI-250: M10.10): key read by name per call, never logged; no key means no call; `max_tokens` always set; 60 s deadline, one retry on 5xx, 1 MiB response cap, no redirects; response schema-checked; logs carry no key, messages or bodies (tested). Tests use a mocked `fetch` only.
- Built (AI-258: M10.11): the only caller, behind the spend gate: reserve the per-task cap before, `max_tokens` sized so two attempts fit, settle after; no price or a refused reservation means no call.
- AI-266: M10.15: key in Secret Manager with a credit limit at or below the monthly cap.
- Severity: low (no key, no route uses `direct` yet). Status: open until AI-266: M10.15 sets the key's credit limit.
