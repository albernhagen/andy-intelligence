# R-AI-181

**Risk:** Verifying stage (AI-181: M6.5). (1) The Verifying check `POST /projects/{p}/tickets/{t}/verifying-check` is a new public route: a caller with the Cloud Tasks invoker's token could flag tickets Needs-you early. (2) A merge whose changed files are all docs or `infra/` skips Verifying; a wrong path rule would let a deploying change reach Done unverified.

**Mitigation / next step:** (1) Same Google OIDC check and 30-a-minute cap as the run watchdog; it only sets Needs-you, and only on a ticket in Verifying for 2 hours. (2) The rule matches `deploy.yml`'s `paths-ignore`; a rename checks both paths; a cut-short or failed file listing verifies. The stage is off (`VERIFYING_SWITCH`) until AI-188: M6.7 turns it on. Detail: `entry-points-and-credentials.md`.
