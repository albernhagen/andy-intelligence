# R-AI-180

**Risk:** Deployment reports (AI-180: M6.4, `POST /deployments`): anyone who can push `deploy.yml` to `main` of a registered repo can record deployments with any image digest and status. A lost report leaves a deployment unrecorded or stuck in `started`.

**Mitigation / next step:** OIDC token checked like the run callbacks (ADR-0019): exact `workflow_ref` `<repo>/.github/workflows/deploy.yml@refs/heads/main`, a registered enabled project; the token sets project and commit, the environment is fixed to `prod`; 1 KB bodies, 30 reports a minute per instance; a finish only for the same project and commit, once. Records are informational until M6.5 on, which recheck what they act on. Detail: `deployments.md`.
