# R-AI-387

**Risk:** The deploy kind (`none` or `cloud-run`, ADR-0114) will decide whether a project's merges deploy. Anyone who could set it to `cloud-run` could later make a project ship that should not, or switch a deploying project to `none` and stop its releases.

**Mitigation / next step:** Owner only (`change_project_settings`) on `PATCH /api/projects/{id}` and MCP `set_deploy_kind`; a fixed two-value list; every change is in the config change log with who and when, and revertable. Nothing reads it yet, so a wrong value has no effect today. Each M6 ticket that acts on it (AI-181, AI-206, AI-199) reviews this risk. Detail: `project-settings.md`.
