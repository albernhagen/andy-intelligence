# R2

**Risk:** Repo secrets (`CLAUDE_CODE_OAUTH_TOKEN`, `TF_VAR_*`) are readable by any workflow on a same-repo branch, including one an agent wrote.

**Mitigation / next step:** Only Andy and his agents push here. Build agents push only through the publish job: App token without `workflows`; patches are refused for what PR jobs holding credentials run: `.github/`, review actions and scripts, `.mcp.json` (Claude token), `infra/`, `.terraform-version` (`terraform-plan`, GCP). Package scripts run only in secret-free jobs; inspect agent branches with `--ignore-scripts` (ADR-0063). Environments with branch rules before M5.
