# R12

**Risk:** A stolen MCP refresh token works for 30 days (Anthropic holds it). Reuse after rotation works 60 s (ADR-0105), then is rejected; the newer token stays valid.

**Mitigation / next step:** Rotation, 60 s grace; allow-list re-check; revoke by deleting `oauthGrants` (runbook `mcp-connector.md` §5). A thief can create backlog tickets, answer questions (Andy still merges), step tickets forward, and edit, comment on, re-parent and reorder them (AI-40: changing what an agent builds or what runs next; history records each change); no delete, forced move or release. No token-family revocation yet. Revisit when `start`, `set_override` or `promote_release` land.
