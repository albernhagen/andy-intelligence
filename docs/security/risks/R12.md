# R12

**Risk:** A stolen MCP refresh token works for 30 days (Anthropic holds it for the connector). Reuse after rotation is rejected but doesn't revoke the newer token.

**Mitigation / next step:** Single use + rotation; allow-list re-check; revoke by deleting `oauthGrants` (runbook `mcp-connector.md` §5). A thief can create backlog tickets, answer questions (Andy still merges), step tickets forward, and edit, comment on, re-parent and reorder them (AI-40: changing what an agent builds or what runs next; history records each change); no delete, forced move or release. Not yet worth token-family revocation. Revisit when `start`, `set_override` or `promote_release` land.
