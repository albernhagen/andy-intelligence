# R-AI-134

**Risk:** A project agent task (`plan-project`, `ideate`; AI-134) reads untrusted text (the idea, the brief, a rejected plan's reason, the repo) and its result is stored as `agent:<runId>`: injected input could steer it to a misleading project plan, or to an epic and a spec PR Andy didn't intend.

**Mitigation / next step:** `project-tasks.md`: owner-only start, read-only tools on every executor, untrusted text JSON-escaped after fixed prompt text, the owner routes' contract schema on every result, `requireOwnAgentTask` (own step, no ticket, no replays), one task per step per project, the dial and global caps. A plan stays a proposal until Andy approves it; a spec PR is Andy's to merge.
