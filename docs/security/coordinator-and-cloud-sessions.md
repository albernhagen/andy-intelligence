# Threat model: Coordinator tools and cloud sessions

The coordinator's scripts (`scripts/coordinator/`, AI-149) and Claude Code cloud sessions (runbook `coordinating-sessions.md` §7 and §8). Risks: [R23](risks/R23.md), [R-AI-149](risks/R-AI-149.md) (`resync` runs branch code as Andy), [R-AI-149-2](risks/R-AI-149-2.md) (a cloud worker acts as Andy) and [R-AI-388](risks/R-AI-388.md) (Andy's Merge button and the queue's own sync). Cloud rows say what one cloud session observed on 2026-11-26 (AI-151: Prove a cloud worker end to end and fix the runbook to match).
