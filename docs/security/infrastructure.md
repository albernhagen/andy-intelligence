# Threat model: Infrastructure

Detail on GCP service accounts, billing, DNS and admin logins. Risk register (every `R<n>` id), assets and mitigations: [threat-model.md](threat-model.md). PRs that change this area update this file; the weekly system review edits only the main file.

## Trust boundaries and entry points

| Entry point                                                                            | Who can reach it                                                                                                                     | Authn/authz                                                                | Notes                                                                                                                                                                                                                                                                             |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pub/Sub topic `budget-notifications` (kill switch on)                                  | Cloud Billing (`billing-budget-alert@system`); any project principal with `pubsub.publisher` (Andy)                                  | IAM                                                                        | A message at ≥150% takes the service offline: a deliberate DoS lever. Only Andy can publish today                                                                                                                                                                                 |
| Deploy path: `deploy.yml` → no-traffic `candidate` revision, then promotion (ADR-0076) | Runs on push to `main` or `workflow_dispatch`, never a PR. The tagged URL `candidate---<service host>` is public while a deploy runs | Deployer bound to `refs/heads/main`. Tagged URL: host rule only (ADR-0044) | A revision that breaks the host rule is exposed on the tagged URL with runtime SA access until the job removes the tag, on promotion or after a failed deploy. Auth regressions are caught only after traffic moves; rollback is by hand (`docs/runbooks/deploy-and-rollback.md`) |
