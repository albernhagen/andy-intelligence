# Threat model: Infrastructure

Detail on GCP service accounts, billing, DNS and admin logins. Risks: [risks/](risks/), one per id; assets, mitigations: [threat-model.md](threat-model.md). PRs that change this area update this file; the weekly system review edits only the main file and risks.

## Trust boundaries and entry points

| Entry point                                                                                              | Who can reach it                                                                                                                     | Authn/authz                                                                | Notes                                                                                                                                                                                                                                                                             |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pub/Sub topic `budget-notifications` (kill switch on)                                                    | Cloud Billing (`billing-budget-alert@system`); any project principal with `pubsub.publisher` (Andy)                                  | IAM                                                                        | A message at ≥150% takes the service offline: a deliberate DoS lever. Only Andy can publish today                                                                                                                                                                                 |
| Same topic in a managed project's GCP project (`managed_projects` entry with the kill switch on, AI-162) | Cloud Billing; any principal with `pubsub.publisher` in that project                                                                 | IAM                                                                        | Same lever for that project's service only; who can publish depends on that project's IAM (R-AI-162)                                                                                                                                                                              |
| Deploy path: `deploy.yml` → no-traffic `candidate` revision, then promotion (ADR-0076)                   | Runs on push to `main` or `workflow_dispatch`, never a PR. The tagged URL `candidate---<service host>` is public while a deploy runs | Deployer bound to `refs/heads/main`. Tagged URL: host rule only (ADR-0044) | A revision that breaks the host rule is exposed on the tagged URL with runtime SA access until the job removes the tag, on promotion or after a failed deploy. Auth regressions are caught only after traffic moves; rollback is by hand (`docs/runbooks/deploy-and-rollback.md`) |
| WIF provider `github-actions` in a managed project's GCP project (`infra/modules/project-env`, AI-201)   | GitHub Actions OIDC tokens for the one repo (name and numeric ID); any other repo is refused                                         | OIDC; each deployer binding narrows further                                | Who can deploy depends on who can merge to that repo's `main` and who can open a same-repo PR (R-AI-201, R-AI-201-2)                                                                                                                                                              |
| `<service>` Cloud Run service in a managed project (AI-201)                                              | The internet, by default (`allow_unauthenticated`), like the control plane                                                           | The app's own auth; Cloud Run IAM only if `allow_unauthenticated = false`  | Caps limit spend (ADR-0028); the safe-deploy smoke tests call it without a token (R-AI-201)                                                                                                                                                                                       |
| `<service>-preview` Cloud Run service (AI-201)                                                           | Anyone who can open a same-repo PR deploys to it; callers need `run.invoker` unless `preview_allow_unauthenticated`                  | Cloud Run IAM (default)                                                    | Runs unmerged PR code, possibly in the prod project; its identity has logs and traces only (R-AI-201-2)                                                                                                                                                                           |
