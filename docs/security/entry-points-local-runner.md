# Threat model: Entry points — local runner (ADR-0089)

Entry-point rows moved unchanged from [entry-points-and-credentials.md](entry-points-and-credentials.md) (AI-221) to give that file room.

| Entry point                                                                                          | Who can reach it                        | Authn/authz                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Notes |
| ---------------------------------------------------------------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| Runner claim `POST /runner/claim` (ADR-0089)                                                         | Internet; meant for Andy's local runner | Runner secret: stored as a SHA-256 hash only, 90-day expiry, revoked in the UI or over MCP; 60 lookups a minute per instance for secrets not verified in the last 10 minutes (a failure drops one), so guesses can't lock out the runner (residual: they can delay a new runner's first claim); one claim per runner per 10 s (`429`); body ≤ 1 KB. Minting: `POST /api/runners`, owner only (`mint_runner`), no MCP tool. Revoking: `POST /api/runners/:runnerId/revoke` and MCP `revoke_runner`, owner only (`revoke_runner`, AI-351, ADR-0143; risk R-AI-351). Listing: `/api/runners` and MCP `list_runners` (AI-294, ADR-0135; risk R-AI-294): allow-listed callers read names, project ids, presence and expiry, never a secret |
| Local agent-task callbacks: `GET …/context`, `POST …/report`, `POST /runs/{id}/heartbeat` (ADR-0089) | Internet; meant for Andy's local runner | Per-run token from the claim (hash stored), bound to one run and runner, dead at the deadline; refused once the runner is revoked; unverified tokens share a 60-a-minute lookup cap; a heartbeat after the run ended is `409`. Lease and runner-away checks `POST /runs/{id}/lease`, `POST /runners/{id}/away`: as the run watchdog                                                                                                                                                                                                                                                                                                                                                                                                   |
