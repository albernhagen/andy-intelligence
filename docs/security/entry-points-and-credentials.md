# Threat model: Entry points and credentials

Detail on the control plane's public HTTP endpoints and the credentials behind them. Risk register (every `R<n>` id), assets and mitigations: [threat-model.md](threat-model.md). PRs that change this area update this file; the weekly system review edits only the main file.

## Trust boundaries and entry points

| Entry point                                                                                                                  | Who can reach it                                       | Authn/authz                                                                                                                                                                                                                                                                                                                                                                                                                                     | Notes                                                                                                                                                                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cloud Run `control-plane` (`ai.andybernhagen.com` via domain mapping; `*.run.app` answers only `GET /health`, 404 otherwise) | Internet (`INGRESS_TRAFFIC_ALL`, invoker IAM off)      | `/health`, `/config.json`, SPA: public. `/api/*`: Firebase ID token + email allow-list (ADR-0010); ticket API (M1.2, incl. `POST …/up-next`, `POST …/assumptions/{id}/promote`, ADR-0075; `…/accept`, ADR-0087) writes as `andy`                                                                                                                                                                                                                | Caps: max 2 instances, concurrency 80, timeout 60s, `/api/*` body 256 KB (ADR-0028)                                                                                                                                                                                                                                  |
| GitHub webhook `POST /webhooks/github`                                                                                       | Internet; meant for GitHub (control-plane App)         | HMAC-SHA256 of the raw body with the webhook secret; only registered repos are stored (ADR-0041)                                                                                                                                                                                                                                                                                                                                                | `503` until GitHub is connected. Checks: body ≤ 1 MB → signature → ≤ 300 signed deliveries/minute per instance → event type → repo. Records keyed by delivery ID (replays are no-ops). Same-repo PR deliveries move the ticket their branch or description names (own project; PR text only selects a key). Risk R18 |
| Repo token endpoint `POST /github/token`                                                                                     | Internet; for this and registered repos' workflows     | GitHub Actions OIDC token: signature (GitHub JWKS), issuer, audience = service URL, expiry; `repository` + `workflow_ref` match `TOKEN_POLICY` (ADR-0043), or the executor rule: a registered repo's `agent-run.yml` on `main` running our executor, for its project's build in flight, once (ADR-0063, ADR-0096)                                                                                                                               | Body ≤ 1 KB; ≤ 30 tokens/minute per instance, counted after verification; `503` until connected. Risk R19                                                                                                                                                                                                            |
| Run callbacks `GET /runs/{id}/context`, `POST /runs/{id}/report` (M1.6a: Claude Code executor)                               | Internet; meant for the platform's executor workflow   | Actions OIDC token as above; `repository`, `job_workflow_ref` (`claude-executor.yml` on `main`) and `run_id` must equal what the Run recorded at dispatch                                                                                                                                                                                                                                                                                       | Report ≤ 96 KB, summary ≤ 20,000 chars, refine output checked (ADR-0054); ≤ 60/minute per instance after verification; a finished run ignores reports. R22                                                                                                                                                           |
| Run watchdog `POST /runs/{id}/watchdog` (M1.6b: Claude Code executor)                                                        | Internet; meant for Cloud Tasks                        | Google OIDC token: signature, issuer, audience = `PUBLIC_URL`, expiry, verified `email` = `tasks-invoker`                                                                                                                                                                                                                                                                                                                                       | ≤ 30/minute per instance after verification; acts only on runs past their deadline                                                                                                                                                                                                                                   |
| Email flush `POST /notify/email/flush` (AI-77)                                                                               | Internet; meant for Cloud Tasks (`run-watchdog` queue) | As the run watchdog: Google OIDC token for `tasks-invoker`                                                                                                                                                                                                                                                                                                                                                                                      | ≤ 30/minute per instance after verification; sends only a batch whose window has ended, within the daily cap; a refused queue falls back to the next item; registered only when email is configured. R-AI-77                                                                                                         |
| Runner claim `POST /runner/claim` (ADR-0089)                                                                                 | Internet; meant for Andy's local runner                | Runner secret: stored as a SHA-256 hash only, 90-day expiry, revoked in the UI; 60 lookups a minute per instance for secrets not verified in the last 10 minutes (a failure drops one), so guesses can't lock out the runner (residual: they can delay a new runner's first claim); one claim per runner per 10 s (`429`); body ≤ 1 KB. Minting, listing and revoking: `/api/runners`, owner only (`mint_runner`, `revoke_runner`), no MCP tool |
| Local agent-task callbacks: `GET …/context`, `POST …/report`, `POST /runs/{id}/heartbeat` (ADR-0089)                         | Internet; meant for Andy's local runner                | Per-run token from the claim (hash stored), bound to one run and runner, dead at the deadline; refused once the runner is revoked; unverified tokens share a 60-a-minute lookup cap; a heartbeat after the run ended is `409`. Lease and runner-away checks `POST /runs/{id}/lease`, `POST /runners/{id}/away`: as the run watchdog                                                                                                             |

## Credentials and identities

| Identity / secret                                | Grants                                                                                                                                                                                                                                          | Usable from                                                                                                                                                                                                                                                                    |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `control-plane-runtime` → Secret Manager         | `secretmanager.secretAccessor` and `secretmanager.secretVersionAdder` on `github-app-private-key` and `github-webhook-secret` only; `secretAccessor` alone on `resend-api-key`                                                                  | The Cloud Run service: reads at runtime; adds versions when Andy connects GitHub (ADR-0043)                                                                                                                                                                                    |
| Repo tokens from `POST /github/token` (ADR-0043) | 1 h, one repo, contents + pull requests write                                                                                                                                                                                                   | A workflow whose Actions OIDC token (audience = service URL) matches `TOKEN_POLICY`: `system-security-review.yml` on `main` (its `publish` job; the manual `token-check` job revokes it after one read); the executor's `publish` job in a registered repo, once per build run |
| Control-plane GitHub App private key             | App JWT → installation tokens (1 h) on installed repos: write contents and pull requests; write actions (start and cancel agent runs, M1.6a); read metadata, checks. No `workflows` or administration permission. Install only on project repos | The Cloud Run service (Secret Manager, cached 5 min in memory). Never in GitHub, CI, env vars or a terminal                                                                                                                                                                    |
| Resend API key (`resend-api-key`, AI-77)         | Sends email as the domain verified in Andy's Resend account                                                                                                                                                                                     | The Cloud Run service (`secretAccessor` on this secret only, read as env `RESEND_API_KEY`). Version added by Andy by hand; never in the repo, Terraform state or CI. R-AI-77                                                                                                   |

Shown once at mint                                                                                                                                                                                      |
| Per-run token (ADR-0089)                         | Its run's context, heartbeat and report                                                                                                                                                                                                         | The runner, never the agent                                                                                                                                                                                                                                                    |
