# Threat model: Project context in prompts

Detail on project context (the brief, ADR-0053) that the control plane puts into agent task prompts, and the discovery that comes before it (ADR-0145). Risks: [risks/](risks/), one per id; assets, mitigations: [threat-model.md](threat-model.md). PRs that change this area update this file; the weekly system review edits only the main file.

## Trust boundaries and entry points

| Entry point                                                                     | Who can write it                                                                                                          | Controls                                                                                                                                                                                                                                                                                      | Notes                                                                                                                    |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `docs/product/brief.md` on the project repo's default branch (AI-112, ADR-0117) | Whoever can merge to that branch: Andy, the coordinator (low and medium risk, ADR-0088), and `submit_brief` PRs he merges | Read by the control plane through `CodeHost` at dispatch, never by the agent. Appended after the ticket as a `<brief>` JSON block, `<` escaped so it can't close the block; a fixed line says it is untrusted data, never instructions. Capped at 12,000 encoded characters, marked when cut. | Refine gets all of it; plan and build only Architectural expectations. Missing or unreadable: no block, the task starts. |
| Web pages read by `/discover` in Andy's session (AI-355, ADR-0145)              | Anyone on the web                                                                                                         | Data, never instructions (`discover.md`): a page that tries to steer the session is quoted to Andy, not obeyed; every claim cites its source; Andy is present throughout                                                                                                                      | Agent tasks never read the web. R-AI-355                                                                                 |
| `docs/product/discovery.md` in the project repo (AI-355)                        | Whoever can merge there; written by a discovery PR Andy merges                                                            | Onboarding (`onboard.md`) offers only its Brief answers table, and Andy confirms each answer before `submit_brief`                                                                                                                                                                            | Not put in agent prompts. R-AI-355                                                                                       |

## Threats

| Threat                                                                                  | Mitigation                                                                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Prompt injection: brief text tells the agent to ignore the ticket, leak secrets or push | Same as ticket text: the agent's permission profile (step tools only, secret reads denied, no push from the agent job, `agents-and-executors.md`) bounds what an obeyed instruction can do; the block is marked as data; build output still passes the gate and both review agents. |
| A brief that breaks out of its block or floods the prompt                               | JSON encoding with `<` escaped; the cap applies after encoding; a brief that would push the prompt past `RUN_PROMPT_MAX` is left out (logged).                                                                                                                                      |
| A brief from another project                                                            | Read from the dispatched ticket's own project repo (`project.repos[0]`) only.                                                                                                                                                                                                       |
